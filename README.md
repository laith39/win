# Win Launcher

لانشر بشكل ويندوز 11 يفتح تطبيقات الهاتف كنوافذ عائمة عبر Shizuku.

## الاستخدام
1. ثبّت APK وشغّل Shizuku (Wireless debugging).
2. افتح التطبيق وأعطِه صلاحية العرض فوق التطبيقات وصلاحية Shizuku.
3. أعد تشغيل الهاتف مرة واحدة بعد تفعيل النوافذ الحرة (أول مرة فقط).
4. اجعله لانشر افتراضي (زر Home).

## التحكم
- زر ابدأ: قائمة التطبيقات + بحث. ضغطة مطولة على تطبيق = تثبيت/إلغاء تثبيت.
- شريط العنوان: اسحب لتحريك النافذة، ▢ تكبير/استعادة، ✕ إغلاق.
- المربع الشفاف في الزاوية السفلية اليمنى: تغيير الحجم.
- ضغطة مطولة على سطح المكتب: تغيير الخلفية.
